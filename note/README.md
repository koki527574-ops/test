# note運用（レン｜AIでどこまで行けるか実験中）

目的は記事数ではなく、**noteから継続的に売上を作ること**。
そのために「記事を量産する仕組み」ではなく「売れる記事の型を毎週1つ学習する仕組み」にしている。

## 毎週やること（3つだけ）

1. その週に起きたことを Claude に渡す
2. 「今週分を作って」と言う
3. 出てきた記事を note にコピペし、画像・タグ・価格・予約日時を設定して予約投稿

日曜に加えて「今週のレビュー」と言うと、数字を聞かれるので答える。それが翌週に反映される。

## 投稿方式

note公式の**予約投稿**（noteプレミアム 月額500円、Web版限定）を使う。
自前のPlaywright / CDP / 非公式APIは使わない。予約さえ入れればnote側のサーバーが公開するので、Macを閉じていてよい。

## 週の構成

基本は**週5本**。良い実体験がある週だけ7本。薄い記事を本数合わせで出すことは禁止。

| 曜日 | 時間 | 役割 | 課金 | 実体験の消費 | 基本週 |
|---|---|---|---|---|---|
| 月 | 21:00 | 主軸記録 | 無料 | 大 | ● |
| 火 | 21:00 | 失敗記録 | 無料 | 大 | ● |
| 水 | 12:00 | 短い観察 | 無料 | 小 | 増量枠 |
| 木 | 21:00 | 実践記録（単体完結） | 無料 | 中 | ● |
| 金 | 21:00 | 有料本体 | 300円 | 大 | ● |
| 土 | 8:00 | 再編集・回遊 | 無料 | ゼロ | ● |
| 日 | 8:00 | 問い | 無料 | 小 | 増量枠 |

木曜は金曜の宣伝記事にしない。単体で完結させ、**より具体的な実践記録を求める人だけ**が金曜へ進む構造にする。

有料記事は条件（`rules.md` 3章）を満たす週のみ。満たさない週は無料5本。これは正常動作。

## 売るもの

- 今: 金曜の有料記事 300円
- 有料記事8〜10本後: 定期購読マガジン 500円/月（単発売り切りは積み上がらないので、ここが本命）
- その先: 仕組みそのものの販売・相談（実績が出てから）

## ファイル

| ファイル | 役割 |
|---|---|
| `experience-stock.md` | 実体験ストック。**ここに無いことは書かない** |
| `rules.md` | 選定基準・無料有料判定・タイトル・重複チェック・Threads |
| `templates.md` | 曜日別テンプレート |
| `learning.md` | **学習ログ。毎週ここを最初に読む** |
| `published-index.md` | 公開済み台帳。重複チェックと回遊記事の材料 |
| `review/TEMPLATE.md` | 週次レビュー |
| `../.claude/skills/weekly-note/SKILL.md` | 「今週分を作って」の実行手順 |

## 学習ループ

```
learning.md を読む
  ↓
今週の検証変数を1つ決める
  ↓
記事生成（確定した型を適用、否定された型を避ける）
  ↓
予約投稿
  ↓
週次レビューで数字を見る
  ↓
learning.md の「次週への申し送り」を書き換える
  ↓（翌週へ）
```

**「次週への申し送り」の書き換えが唯一の接続点。** ここが飛ぶとループが切れて量産システムに戻る。
