# 実体験ストック

架空の体験を書かないための唯一の材料置き場。**ここに無いことは記事にしない。**

## 使い方

毎週、その週に起きたことをこの下に追記する。書式が埋まらない項目は空欄のまま残す。
空欄を埋めるために思い出を創作しない。空欄のまま残っていること自体が「その記事はまだ書けない」という情報になる。

## 記入フォーマット

```
### EXP-000 短いラベル
- 起きたこと:（事実のみ。解釈や感想を混ぜない）
- 時期:
- その時どう思ったか:（無い場合は空欄。捏造しない）
- その後どうなったか:（未決着なら「まだ分からない」と書く）
- 数字・固有名詞:（金額/日数/回数/ツール名。無ければ空欄）
- 濃さ: 大 / 中 / 小
- 主題タグ:（下の語彙から1〜2個）
- 使用状況: 未使用 / 使用済み → 記事URL
```

### 濃さの判定

| 濃さ | 条件 | 使える曜日 |
|---|---|---|
| 大 | 経過が3段階以上ある。感情の動きがある。未解決 or 方針転換を含む | 月・火・金 |
| 中 | 出来事＋結果はあるが経過が短い | 木 |
| 小 | 気づき・観察のみ。出来事としては小さい | 水・日 |

### 主題タグ語彙（重複判定に使う。勝手に増やさない。増やす時はこの行を更新する）

`言語化` `サイト制作` `自動化構築` `VPS` `note自動投稿` `AI文章の不自然さ` `画像生成API` `作りすぎ` `収益化` `一人会社` `判断・方針転換` `ツール選定`

### 使用禁止ルール

- **「その時どう思ったか」が空欄のストックは、月・火・金に使えない。** 感情を創作することになるため。木・水・日で事実ベースに書く。
- **「数字・固有名詞」が空欄のストックは、有料記事に使えない。** 有料部分の価値は具体性なので。
- 使用済みストックは消さない。土曜の回遊記事で再編集の材料になる。
